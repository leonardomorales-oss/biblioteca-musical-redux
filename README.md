# Biblioteca Musical con Redux

Versión con estado global, búsquedas de TheAudioDB y biblioteca.

## Tecnologías

- React
- Redux
- React Redux
- React Router
- styled-components
- TheAudioDB API

## Instalación y ejecución

```bash
npm install && npm run dev
```

Comprobaciones disponibles: `npm run lint` y `npm run build`.

## Uso

Busca álbumes y gestiona la biblioteca.
